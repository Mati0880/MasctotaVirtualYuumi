# MasctotaVirtualYuumi
Codigo de python para mascota virtual
Aqui esta mi mascota virtual Yuumi! , Hice esta mascota virtual basada en una especie de togodachi
tiene estadisticas de felizidad y energia, tambien tiene 4 diferentes opciones para jugar con el.

#1 Alimentar
 Con esto podras "alimentar" a tu mascota virtual para subirle la energia y felicidad

#2 Jugar
 Con esta opcion podras "Jugar" con tu mascota, lo que subira su felicidad pero bajara su energia

#3 Ver estado de salud
 con esta opcion veras las estadisticas ocultas y tambein un sprite de la mascota hecho con ASCII art

#4 No hacer nada
 Con esto simplemente no haces nada y le baja la felicidad y la energia a la mascota
